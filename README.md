# Kill My Ex — MVP v1.0

MVP web completo del primer loop jugable.

## Incluye

- Onboarding.
- Crear múltiples exes.
- Primer ex placeholder: `test`.
- 8 arquetipos disponibles.
- Dashboard post-primer-ex.
- Lista de exes.
- Detalle de ex.
- Flujo de duelo.
- Mini shooter vertical jugable.
- Victoria / patrón roto.
- Por enterrar.
- Cementerio.
- Detalle de tumba.
- Desenterrar.
- Editar epitafio.
- Persistencia local con `localStorage`.
- Concept boards integrados.
- Responsive mobile.
- Manifest básico para instalar como web app/PWA en algunos navegadores.

## Cómo probar

Abre `index.html` en un navegador moderno.

## Controles del duelo

Desktop:
- Flechas o WASD para mover a Luz.
- Disparo automático.
- Botón "Contacto Cero" cuando Claridad llega a 100%.

Móvil:
- Arrastra a Luz con el dedo.
- Disparo automático.
- Toca "Contacto Cero" cuando esté listo.

## Cómo probar en móvil

La mejor forma es subir la carpeta a:
- Netlify Drop
- Vercel
- GitHub Pages

Luego abre el enlace desde el teléfono.

## Nota

Este MVP es un prototipo funcional web. No es todavía una app nativa de iOS/Android ni un build de Godot/Unity.
